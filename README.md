This project consists of a django server that runs on a computer to a domain to be on the internet. The server address is 'cse350@ddns.net'. It uses the views.py and the urls.py to create webpages and uses html and css to populate those webpages. For the interactive calendar is uses the FullCalendar from JavaScript to make it so the user can select a date instead of having to type one in manually like with normal inputs. To add the option of creating or viewing entries on the calendar there is a form that asks the user to select one or the other which takes them to their respective webpages. When viewing a created entry it will show the sum of all the entries at the bottom of the webpage as well as showing each entries individual calorie count. When the user wants to delete and entry they click the delete button and it will remove that entry from the database. When creating and account it takes you to another for for creating a user and makes sure that it is a unique username and email by checking the database. Once you select signup it will connect to the SMTP server we have set up to send the emails to the email address provided. When the user enters the verification code it will redirect them back to the login page and activate their account by setting the variable 'is_active' to 1.
