This project consists of a Django server that runs on a computer to a domain to be on the internet. The server address is 'cse350.ddns.net'. On the server side, this web application uses Python, Django Framework, and the SQLite database for persistence. On the client side, HTML, JavaScript, and CSS are used to present the user interface. When the user first accesses the application, they are prompted to either log in, sign up, or reset password. When creating an account, the user is taken you the signup page. When creating a user, the application ensures that it is a unique username and email by checking the database. Once you select signup it will connect to the SMTP server we have set up to send a verification email to the email address provided. When the user enters the verification code it will redirect them back to the login page and activate their account by setting the variable 'is_active' to 1. If the user forgets or wants to reset their password, they can select the forgot password link. When the user selects forgot password, it takes them to the request_reset webpage and asks the user for the email for the account, and a new password they would like to set it to. The SMTP server then sends the verification code for the user to input and the resets the password when provided with the code, it then redirects them to the login page. When the user logs in the user is taken them to the interactive calendar. For the interactive calendar is uses the FullCalendar from JavaScript to make it so the user can select a date or change the months by selecting the arrows on the right corner of the calendar, instead of having to type one in manually like with normal inputs. To add the option of creating or viewing entries on the calendar there is a form that asks the user to select one or the other which takes them to their respective webpages. When the user selects a day and click view entries, it will show the sum of the calories of all the entries for the selected day at the bottom of the webpage as well as showing each entry's individual calorie count. When the user wants to delete an entry, they click the delete button and it will remove that entry from the database. When the user has completed their session, they can select logout and are returned to the login page.
